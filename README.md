# What is the project
OnPDV is a cloud base project writed on golang and react js. You can manage your inventary, sells and client in a modern and fast pdv.


## Development
Install [pre-commit](https://pre-commit.com) (`pipx install pre-commit`) and run `make install-hooks`.
Lint and tests for `client/` and `server/` then run on every `git push`.
Pull requests to `develop` and `main` run the same checks in GitHub Actions.
